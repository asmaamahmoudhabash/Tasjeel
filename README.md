# Tasjeel Regulatory Office

Website for Tasjeel Regulatory Office, a regulatory affairs consultancy in Cairo, Egypt (EDA and NFSA).

- Pages: Home, About Us, Services, Products (coming soon), Contact Us
- Languages: English (default) and Arabic, with a language switch in the header

## Run locally

```
npm install
npm run dev
```

## Build

```
npm run build
```

The ready-to-publish site is in the `docs` folder (served with GitHub Pages).
